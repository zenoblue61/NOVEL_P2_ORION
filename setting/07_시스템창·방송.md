# 07. 시스템 창 · 방송 채팅 규칙

> 정본: 확정. CLAUDE.md 2장의 표는 이 파일의 요약이다.

## 시스템 창
- 표기 형식: 【확정 필요】 예: `[ ... ]` 한 줄 / 코드블록 / 들여쓰기
- 1회차 최대 노출 횟수: 【확정 필요】
- 창에 노출 가능한 정보: 【확정 필요】
- 창에 노출 금지인 정보: 【확정 필요】 (독자에게 먼저 답을 주는 정보 등)
- 창은 누구에게 보이는가: 【확정 필요】

## 방송 채팅
- 표기 형식: 【확정 필요】 예: `닉네임: 내용` / 말머리 기호
- 닉네임 규칙: 【확정 필요】 (고정 시청자 목록은 아래)
- 1장면 최대 줄 수: 【확정 필요】
- 채팅이 할 수 있는 역할: 정보 제공 / 분위기 / 압박 / 코미디 — 【확정 필요】
- 채팅이 하면 안 되는 것: 【확정 필요】 (주인공 대신 추리를 끝내기, 설정 설명 대행 등)
