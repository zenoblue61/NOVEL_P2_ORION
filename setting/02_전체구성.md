# 02. 전체 구성 (280화 구간 설계)

> 가까운 구간은 확정, 먼 구간은 계획. 구간이 끝날 때 다음 구간을 상세화한다.
> 각 구간은 「목표 → 시도 → 저항 → 선택 → 결과 → 다음 구간을 여는 변화」를 갖는다.

| 구간 | 회차 범위 | 목표 | 대립·장애 | 전환점 | 도착점(결과) | 다음 구간에 넘기는 조건 | 상태 |
|---|---|---|---|---|---|---|---|
| 1. 도입 | 1~【】 | 결핍과 핵심 장치를 사건으로 제시, 되돌리기 어려운 첫 선택 | | | | | 제안 |
| 2. 확장 | 【】~【】 | 작은 성취 + 더 큰 이해관계·대가 노출 | | | | | 제안 |
| 3. 전환 | 【】~【】 | 기존 해결 방식이 통하지 않는 사건으로 목표·관계·진실의 의미 변경 | | | | | 제안 |
| 4. 수렴 | 【】~280 | 준비한 능력·관계·증거·선택을 결합해 중심 갈등 해결 | | | | | 제안 |

위 4구간은 틀일 뿐 고정 비율이 아니다. 실제 작품의 아크 수에 맞춰 행을 늘린다.

## 구간 점검 체크 (구간 종료 시)
- 결말까지 남은 필수 사건 수와 남은 회차 수가 맞는가.
- 같은 문제·같은 해결·같은 보상이 이름만 바뀌어 반복된 구간이 있는가 → 합치거나 삭제.
- 새 핵심 갈등 추가보다 기존 약속의 회수가 우선인가 (3구간 이후).
