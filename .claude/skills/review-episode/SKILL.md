회차 번호: $ARGUMENTS 의 첫 토큰. 두 번째 토큰이 「수정」이면 검수 후 수정본까지 쓴다.

1. `python scripts/extract_context.py --ep N` 으로 컨텍스트를 만들고 읽는다. 이어 `episodes/epNNN.md` 전문을 읽는다.
2. 아래 순서로 점검한다. 구조·인과 → 인물·감정 → 설정·시점 → 문장·표기.
   - 이번 화가 직전 화의 끝 상태에서 시작하는가.
   - 인물별 정보 보유(current_state)에 없는 사실을 인물이 알거나 이용하는가.
   - 06_스킬 조건·비용·현재 초인화 단계를 지켰는가.
   - 07 시스템 창·방송 채팅 규칙(형식·횟수·금지 정보)을 지켰는가.
   - 브리프의 「바꾸지 말 사실」이 유지됐는가. 브리프에 없는 복선을 심거나 회수했는가.
   - 10_문체규칙의 시점·시제·금칙을 어겼는가. 인물 말투가 04_인물과 맞는가.
   - 회차에 남는 변화가 있는가. 분량 채우기 반복이 있는가. 말미 유형이 연속 3화 같은가.
3. 결과를 표로 낸다: 문제 | 원문 근거(인용 1~2줄) | 독자 경험에 미치는 영향 | 최소 수정안. 확인 못 한 항목은 「미확인」. 근거 없는 점수·통과율을 만들지 않는다.
4. 「수정」 요청이 있으면 해당 장면만 고쳐 파일을 갱신하고 check_length / lint 를 다시 돌린다. 요청 범위 밖은 건드리지 않는다. 프런트매터 상태를 「검토완료」로 바꾼다.
5. 설정 자체를 바꿔야 해결되는 문제는 수정하지 말고 「검토 필요: 원래 내용 → 변경안 → 영향 회차 → 최소 수정안」으로 보고한다.
